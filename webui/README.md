# VibeShorts Web UI

Placeholder for a future browser studio. Shared editing logic should stay in `src/vibeshorts/` (timeline, agents, Vertex, pipeline). This folder will own UI-only code, similar to how `cli/` owns the command-line interface.

The current `vibeshorts studio` command launches a small FastAPI timeline + agent preview from the shared `studio` package. That will move here when the Web UI is expanded.
